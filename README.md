# Efficient Closure Learning in Dynamical Systems: A Comparison of Data-Assimilated and Embedded Approaches

This repository contains the source code to replicate the results for analytical test functions presented in [1].

[1] R. Bandy, T. Portone, M. Khalil, E. Crislip, and K. Neal, “Efficient Closure Learning in Dynamical Systems: A Comparison of Data-Assimilated and Embedded Approaches.” 2026. [Online]. Available: https://arxiv.org/abs/2611.03612


## Running the code

To get the appropriate Python environment using `uv`, simply call `uv sync` within this directory.
Activate the local virtual environment by calling
```
source .venv/bin/activate
```

Results should be generated by invoking the bash scripts in the following order:
- `run_embedded_training.sh`
- `run_staged_training.sh`
- `run_embedded_generalization.sh`
- `run_staged_generalization.sh`
Results for the embedded NN training, EnKF, and STAGED NN training, each have python scripts for 
diagnostic plotting.

Aggregated results that are presented in the manuscript can be visualized with the `visualize_results.ipynb` notebook.
